# ИИ‑инструменты для преподавателей биологии и географии

## Описание
Справочник по использованию ИИ-сервисов для упрощения подготовки к урокам. Содержит список платформ и модель «3 шага» для внедрения ИИ в учебный процесс.

## Цели
- познакомить с ИИ-сервисами для создания УММ;
- дать классификацию сервисов по задачам;
- описать алгоритм работы с ИИ (3 этапа);
- предоставить шаблоны промптов.

## Содержание
- список ИИ-платформ (9 категорий);
- модель «3 шага» (подготовка → адаптация → контроль);
- шаблоны промптов (20+ примеров);
- разделы для биологии и географии.

## Как использовать
1. Откройте HTML-файл в браузере.
2. Выберите тип задачи (например, «генерация презентации»).
3. Найдите список сервисов в соответствующем разделе.
4. Используйте шаблоны промптов для взаимодействия с нейросетями.

## Технологии
- HTML, CSS.

## Примеры использования
- создание презентации через Gamma/Curipod;
- генерация конспекта с помощью YandexGPT;
- создание викторин в Образавр/Umaigra.

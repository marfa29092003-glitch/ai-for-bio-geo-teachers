Использование технологий искусственного интеллекта при обучении биологии и географии
Использование технологий искусственного интеллекта
Современное школьное образование переходит в цифровой формат обучения, и преподаватели ежедневно сталкиваются с необходимостью готовить больше учебно-методических материалов (УММ) с цифровым уклоном: планы-конспекты, технологические карты уроков, презентации, дифференцированные задания, рабочие листы, наглядные пособия и так далее. Особенно это заметно на уроках географии и биологии - дисциплинах, где очень важны актуальность фактов, наглядность и вариативность подачи материала. Нагрузка на преподавателя растёт и для облегчения и делегирования работы на помощь приходят технологии искусственного интеллекта (ИИ), которые способны частично автоматизировать рутинные процессы и освободить время преподавателя.

В результате работы были отобраны платформы ИИ, которые помогут учителю снизить нагрузку на различных аспектах подготовки к уроку. Были учтены такие факторы как доступность, быстрота, простота использования ресурса, опыт коллег и отзывы пользователей.

1. Нейросети для поиска информации и генерации планов‑конспектов уроков
К платформам, которые могут помочь преподавателю написать план‑конспект, относятся: Deepseec, ChatGPT, YandexGPT, АлисаAI, GigaChat, You.com, AI TXT, Neurosets, Zaochnik AI.

Они могут сгенерировать текст, который будет опираться на учебник.

Также они могут генерировать задания для учеников, таблицы, тесты с ответами, пояснения материала под уровень класса.

Есть также ещё некоторые бесплатные платформы, такие как Eduaide.Ai, Wooflash — платформы с готовыми шаблонами материалов, конструктор уроков.

Платформа Neuralwriter может писать промпт для урока, который в последующем может быть вставлен в любой из выше перечисленных платформ.

Study AI, Кэмп, ruGPT, SmartBuddy, WordyBot — платные специализированные платформы, которые создают качественный план‑конспект с графиками, таблицами, картинками.

2. ИИ‑платформы для сжатия текстов, проверки грамматики, озвучивания текста
К сервисам, которые находят ошибки и улучшают стиль письма, относятся: Grammarly и его отечественный аналог Яндекс.Спеллер.

К сервисам, которые могут сделать краткий пересказ документов, относится Пересказ Яндекс.

К сервисам, которые могут озвучить текст различными голосами, относятся: OpenAi.fm.

3. ИИ‑платформы для генерации презентаций к урокам
К платформам, которые по запросу генерируют презентации с картинками, графиками, относятся: Gamma, Curipod.

4. ИИ‑платформы для генерации викторин к урокам
К платформам, которые могут создать урок с викторинами, где можно найти готовые шаблоны либо сделать игру самому, относятся: Образавр, Umaigra, Superkid.

5. ИИ‑платформы для поиска картинок и генерации изображений к урокам
К сервисам, которые могут помочь создать различные изображения к уроку, относятся: Шедеврум, Leonardo.Ai, Dream by Wombo, Kandinsky.

Из минусов: генерируются картинки не быстро (1–3 минуты), не всегда соответствуют запросу, поэтому нужно писать подробный конкретный запрос и пробовать несколько раз, если генерация неправильная.

Бесплатная платформа Admem позволяет создать свой «мем» по теме вашего урока.На платформе представлены шаблоны, и можно наложить свой текст, который может также за вас сгенерировать Deepseec или АлисаAI.

В приложении Pinterest или его российском аналоге Pinme можно найти картинки для презентации (фон и картинки по теме урока), «мемы», готовые рабочие листы.

Существует бесплатная платформа Photoroom, с помощью которой вы можете удалить фон с фотографии.

6. ИИ‑платформы для генерации рабочих листов к урокам
К платформам, которые могут помочь создать рабочий лист к уроку по разным предметам, для разных классов, относятся: Обучай, Seapic.

7. ИИ‑платформы для генерации графиков и диаграмм
К сервисам, которые могут помочь создать различные графики и диаграммы к уроку, относятся: Napkin AI, Julius AI, Deepseec.

8. ИИ‑платформы для преподавателей географии
География основана на визуальных данных, таких как карты, схемы и диаграммы.

К сервисам, с помощью которых преподаватели могут создавать и использовать интерактивные карты, которые позволяют учащимся лучше понимать территориально-пространственные процессы относятся: Яндекс.Карты, Google.Карты, Google Earth, ЭверГИС и Padwork

Лучшими для интерактивной карты являются платформы ЭверГИС, Google Карты и Padwork.

ЭверГИС - это бесплатная отечественная ГИС-платформа, которая позволяет работать с векторными, растровыми и внешними данными, редактировать геометрию пространственных объектов и проводить анализ работы.

Padwork - платформа, которая предлагает шаблон «География», и позволяет создавать карты для обучения с презентацией, где можно добавлять маркеры, создать карточки регионов с информацией о них.

К приложениям, которые могут предложить изучение географической номенклатуры через игру или викторину, относятся: GeoGuessr, Seterra и StudyGe.

Для автоматизации проверки пройденной темы можно использовать платформу ВЗНАНИЯ - это бесплатная отечественная ИИ платформа, которая позволяет создавать интерактивные уроки и упражнения, основываясь на конструкторе игр и интерактивных видео с заданиями.

9. ИИ‑платформы для преподавателей биологии
Биология, как и география, дисциплина основанная на визуальных данных, поэтому ИИ могут предложить платформы, специализирующиеся на данной дисциплине.

Например Labster, PraxiLabs и Virtual Biology Lab - это онлайн-лаборатория, где можно проводить виртуальные эксперименты.

Ее плюсы в том, что эта платформа использует для моделирования реальные лабораторные условия, и позволяет ученикам проводить опыты без риска и затрат. Подходит для изучения генетики, микробиологии, молекулярной биологии, биохимии.

Платформа PhET Interactive Simulations помогает с интерактивными симуляциями для изучения физических и биологических процессов.

А платформа IBM Watson может помочь разрабатывать индивидуальные учебные программы, использовать инструменты для автоматической оценки и анализа знаний учеников.

Socratic от Google, Eco, Educaplay - мобильные приложения, которые помогают учащимся в решении научных задач, можно онлайн создать экосистему и следить за ее существованием. Она может анализировать вопросы по биологии, предлагая ответы и пояснения.

Платформа для генерация интерактивных заданий и викторин: Prodigy - это приложение для изучения биологии, основанное на игровых элементах. Использует ИИ для адаптации уровней сложности и типов вопросов в зависимости от успехов ученика.

Стоит так же подчеркнуть, что на данный момент многие нейросети могут работать с перебоями, но нейросети отечественного производства показывают стабильную работу и регулярно обновляются. К ним относятся: YandexGPT, АлисаAI, GigaChat, AI TXT, Study AI, SmartBuddy, Кэмп, Zaochnik AI, ruGPT, Яндекс.Пересказ, Яндекс.Спеллер, Gamma, Образавр, Umaigra, Superkid, Шедеврум, Kandinsky, Admem, Pinme, Обучай, Яндекс.Карты, ЭверГИС, ВЗНАНИЯ, Padwork.

10. Модель интеграции ИИ‑инструментов в рабочий процесс преподавателя
Разработанная модель построена по принципу «трёх шагов» - каждый этап чётко разграничен и выполняет свою функцию.

Этап 1. Подготовка контента. На этом этапе ИИ-инструменты берут на себя сбор и первичную обработку информации. Для подготовки контента к уроку алгоритм включает в себя:

- Поиск и сбор информации: использовать АлисаAI, GigaChat и/или YandexGPT для поиска актуальных данных по темам; верифицировать источники через официальные базы: Росстат (для географии), учебники ФПУП и научные статьи РИНЦ (для биологии).

- Выделение ключевых элементов: применить Яндекс.Пересказ для сжатия больших текстов до тезисов; использовать АлисаAI, GigaChat, YandexGPT, ruGPT и/или Deepseec для структурирования информации в виде планов, таблиц или списков.

- Генерация плана-конспекта урока: ввести запрос в АлисаAI, GigaChat, YandexGPT, GigaChat, Deepseec и/или ruGPT: «Составь план-конспект урока по теме «_» для «_» класса. Включи цели, задачи, этапы урока, основные понятия и домашнее задание».

- Создание текста для презентации: сгенерировать слайды с тезисами через Gamma - платформа автоматически подберёт дизайн и структуру; либо использовать Curipod для генерации презентации с визуальными элементами.

Можно так же использовать АлисаAI, GigaChat, YandexGPT, Deepseec и/или ruGPT для генерации текста для презентации, используя команды (промпты): «Составь текст к презентации по теме «_» для «_» класса, основываясь на данных «Вписать данные, которые использовались или прикрепить документ (файл)»», а оформление самой презентации сделать под ваш стиль.

- Поиск и генерация изображений, графиков, карт:

География: создать интерактивные карты через Яндекс.Карты, ЭверГИС, Padwork или Google Карты (добавить маркеры с информацией о месторождениях, городах, климатических зонах); использовать Google Earth для 3D-визуализации рельефа.

Биология: сгенерировать схемы в Шедевруме или Kandinsky (подробный промпт: «Схема фосфолипида: гидрофильная головка - синий цвет, гидрофобные хвосты - красный. Стиль - учебная иллюстрация»); построить диаграммы через NapkinAI или JuliusAI.

Использовать общие изображения для фона и иллюстраций: Pinme (поиск по ключевым словам), Pinterest или генерация в Dream by Wombo.

- Разработка рабочих листов: создать упражнения и задания в Обучай или Seapic - платформы предлагают шаблоны под уровень класса; добавить интерактивные элементы через ВЗНАНИЯ (конструктор упражнений).

Этап 2. Адаптация материалов. Полученный контент адаптируется под конкретные педагогические задачи и уровень учеников:

- Дифференциация сложности текста: упростить или усложнить формулировки с помощью АлисаAI, GigaChat, YandexGPT, ruGPT и/или Deepseec: «Перепиши текст для «_» класса, замени термины на простые аналоги, сократи предложения» ; для профильного уровня: «Дополни текст примерами, включи термины: «_»» .

- Формирование вариативных заданий: базовые вопросы: сгенерировать в Eduaide.Ai или Wooflash (шаблоны тестов и викторин); интерактивные игры: создать в Образавр, Superkid и/или Umaigra (викторины по номенклатуре или биологическим схемам); проектные задачи: сформулировать через Prodigy (адаптация сложности под успехи учеников).

- Добавление мультимедийных элементов: озвучить ключевые фрагменты текста через OpenAi.fm (выбор голоса и темпа); создать «мемы» для мотивации учеников в Admem (шаблон + текст от АлисаAI, YandexGPT или Deepseec с помощью промпта: «Создай мем на тему «_» для «_» класса»); включить виртуальные эксперименты: Google Earth (география - 3D-визуализации рельефа) или Labster (биология - моделирование биологических процессов).

- Интеграция интерактивных карт, онлайн-лабораторий и симуляций:

География: работать с интерактивными картами на платформах: Яндекс.Карты, ЭверГИС, Padwork, Google.Карты и/или Google Earth; использовать игры для проверки номенклатуры: StudyGe, GeoGuessr и Seterra; внедрение платформы ВЗНАНИЯ для автоматизации проверки пройденной темы.

Биология: работать с онлайн-лабораториями: Labster, PraxiLabs и Virtual Biology Lab; использовать платформу PhET Interactive Simulations для изучения физических и биологических процессов; внедрение платформы IBM Watson для автоматической оценки и анализа знаний учеников; использовать игр: Socratic от Google, Eco, Educaplay для решения научных задач (создание онлайн экосистемы); использовать платформу Prodigy для генерация интерактивных заданий и викторин.

Этап 3. Контроль качества. Финальный этап гарантирует достоверность и методическую ценность материалов. Комбинация автоматической и экспертной проверки:

- Автоматическая проверка текста: исправить ошибки и стилистику через Яндекс.Спеллер или Grammarly; проверить факты: кросс-ссылка с учебниками (ФПУП), научными статьями, официальными данными (Росстат, Минприроды).

- Экспертная оценка визуальных материалов: убедиться в точности карт и схем (сравнение с учебными атласами); проверить корректность биологических иллюстраций (соответствие молекулярных моделей реальным структурам).

- Тестирование интерактивных элементов: запустить пробную викторину в Umaigra, Образавр или Prodigy, проанализировать результаты; проверить работу виртуальных лабораторий (Labster) на соответствие учебным целям.

Финальная корректировка:

Внести правки в текст (АлисаAI, GigaChat, YandexGPT, и/или Deepseec: «Упрости абзац о «_», добавь пример из жизни»);

Обновить карты (добавить актуальные данные);

Адаптировать задания под уровень класса (через Prodigy или ВЗНАНИЯ).

Экспорт и подготовка к уроку: собрать все материалы в единый пакет: презентация, рабочие листы, интерактивная карта или онлайн-лаборатория, викторина; сохранить в совместимых форматах (PDF, PPTX, ссылки на онлайн-ресурсы).

Результат: готовый урок с оптимизированным контентом, где ИИ-инструменты автоматизировали рутинные задачи, а преподаватель сохранил контроль над качеством и методикой.

Роль преподавателя в модели. Несмотря на автоматизацию, преподаватель остаётся центральным звеном: формулирует чёткие запросы к ИИ-инструментам (промпты), задавая параметры по содержанию, стилю и сложности; выбирает источники данных, отсеивая ненадёжные; корректирует сгенерированный контент, устраняя ошибки и добавляя авторские акценты; адаптирует материалы под специфику своего класса (уровень подготовки, интересы учеников).

Преимущества модели: сокращение времени на подготовку уроков на 30-40%; обеспечение актуальности данных за счёт автоматической актуализации; повышение вариативности заданий без увеличения нагрузки на учителя; стандартизация качества материалов (единые требования к текстам и иллюстрациям).

11. Промпты
Многие сервисы и платформы можно заменить, если уметь писать промпты (запрос/команда инструкций для нейросети).

Например, промпт для подробного обучающего конспекта: «Сделай подробный обучающий конспект с пояснениями по теме «_». Раскрой ключевые термины, поясни сложные моменты простым языком, добавь короткие примеры, если это уместно», или же промпт для конспекта для презентации: «Сделай конспект в виде коротких тезисов, которые можно переносить в презентацию: 5-7 ключевых блоков по теме, каждый - до 2 предложений».

Промпт - это короткая формулировка, которая предоставляет информацию нейросети о том, что именно требуется от нее. Это может быть вопрос, инструкция или даже просто ключевые слова. Важно понимать, что качество промпта напрямую влияет на результаты обучения нейросети.

База шаблонов универсальных промптов для преподавателей, которые можно адаптировать под себя.

«Составь конспект урока по теме _ для _ класса. Укажи цели, оборудование, ход урока, проверочные задания и объяснение материала простыми словами».

«Создай упражнения трёх уровней сложности по теме _ для учеников, которым нужно подтянуть навыки».

«Подготовь карточки с картинками и подсказками для учеников _ лет по теме _».

«Преобразуй этот текст (вставка текста) в адаптированный вариант для детей с ОВЗ или для слабых читателей».

«Предложи 5 вариантов объяснения сложной темы простым языком и добавь игровые элементы».

«Подбери 10 вопросов для устного опроса по теме _ для _ класса: от простого к сложному».

«Составь тест из 15 заданий по теме _ с вариантами ответов и ключом для проверки».

«Придумай 5 игровых упражнений для закрепления темы _ для учеников _ класса».

«Сделай список типичных ошибок учеников по теме _ и предложи тренажёр для их отработки».

«Сформируй задания для проектной работы по теме _ с примерными этапами и критериями оценивания».

«Сделай подборку заданий для сильных учеников по теме _, усложнив уровень объяснений и примеров».

«Составь адаптированный вариант контрольной работы по теме _ для учеников, которым нужна поддержка».

«Составь список вопросов для рефлексии после урока по теме _, которые помогут ученикам осознать, что они узнали».

«Сделай краткий конспект этой темы (вставка текста) в формате шпаргалки для повторения перед проверочной».
